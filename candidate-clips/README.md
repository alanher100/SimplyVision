
# Candidate Clips Feature

## Overview
The Candidate Clips feature allows SimplyVision users to review AI-detected basketball highlights before approving them for the video library.

## Jira Stories

- SV-12: View and Review Candidate Clips
- SV-18: Display Suggested Statistics and Event Labels
- SV-23: Add and Edit Event Labels
- SV-28: Confirm or Reject Candidate Clips

## Planned Features

- Display candidate basketball clips
- Show player and game information
- Search and filter candidate clips
- Display AI-generated statistics and confidence scores
- Display suggested event labels
- Add, edit, and remove event labels
- Confirm or reject candidate clips
- Update clip review statuses
- Navigate to the next candidate clip

## Current Status

- Figma UI mockups completed
- Jira stories and subtasks created
- GitHub feature branch created
- Implementation pending team technology decisions
