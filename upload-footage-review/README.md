# Upload Footage / Footage Review

## Overview
The Upload Footage/Footage Review feature allows SimplyVision user to upload raw video files onto the application and review the raw file before saving, with the option of adding details. This does not refer to the AI footage review feature.

## Jira Stories
* SV-117 Upload Footage - Navigate to Upload Footage Workspace
* SV-118 Upload Footage - Upload Raw Basketball Video Files
* SV-119 Upload Footage - Preview Recently Uploaded Footage
* SV-120 Footage Review - Monitor Raw Video Upload Progress
* SV-121 Footage Review - Edit Uploaded Raw Footage Details
* SV-122 Footage Review - Save Uploaded Raw Footage Details
